Moodless es un diario visual impulsado por IA que te permite registrar, analizar y expresar tu estado emocional de forma creativa, sencilla y automática.

✨ Características
🧠 Registro emocional inteligente: escribe cómo te sientes y la IA lo interpreta
🎨 Diario visual: convierte emociones en imágenes o estilos visuales
📊 Seguimiento de estado de ánimo: visualiza tu evolución emocional con el tiempo
💬 Reflexiones asistidas por IA: obtén insights sobre tus entradas
🔒 Privacidad primero: tus datos son tuyos
⚡ Rápido y minimalista: diseñado para uso diario sin fricción

🛠️ Tech Stack
Frontend: Next.js / React
Backend: Node.js / API Routes
IA: LLMs (OpenAI / otros modelos)
Base de datos: PostgreSQL / Firebase (según implementación)
Styling: TailwindCSS
