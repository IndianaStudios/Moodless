=============================================================================
NOTAS IMPORTANTES:
=============================================================================

1. Las variables con prefijo VITE_ son para el FRONTEND (Vite). 
   Si las marcas como sensibles, el navegador NO podrá acceder a ellas.

2. Las variables SIN prefijo son para el BACKEND (API routes).
   Estas DEBEN ser sensibles porque contienen claves privadas.

3. La FIREBASE_PRIVATE_KEY debe copiarse EXACTAMENTE como está arriba,
   incluyendo todos los saltos de línea y sin espacios extra.

4. Después de agregar todas las variables, haz clic en "Redeploy" para que
   los cambios surtan efecto.

5. Si usas extensiones como Bitdefender Traffic Light, desactívalas
   porque pueden bloquear peticiones y dar el error "Search engine null".
